# Projeto de Leitura de PDF
### O que ele faz?
  Ferramenta web client-side que lê o PDF do Projeto Pedagógico de Curso (PPC), extrai disciplinas, semestres, cargas horárias e pré-requisitos por coordenadas espaciais e gera o JSON estruturado para o fluxograma curricular.

### Objetivo:
  Ingressar este código em outro projeto de fluxo de matérias, para buscar as matérias altomaticamente.
